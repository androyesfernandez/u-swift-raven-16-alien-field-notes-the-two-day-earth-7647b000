A tiny program with one job: it writes a single one-line review of
planet Earth, left by an alien tourist, into `/output/entry.txt`. The
alien came for the famous blue marble, spent the whole trip queuing to
prove it was allowed to land on it, and rates the planet lovely and the
paperwork not.

## Run it

```sh
node main.ts
```

That writes the review to `/output/entry.txt`. The program uses only
the Node standard library.
